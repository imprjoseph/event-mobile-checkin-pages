# iMPR 活動行動報到（公開前端）

這個儲存庫只包含手機 QR Code 報到前端，透過 GitHub Pages 發布。

- 不包含與會者名單、Email 或報到紀錄
- 正式資料由 Google Apps Script 與 Google Sheet 管理
- 支援連續掃描、姓名／公司查詢、手動序號、伴手禮與午餐登記
- 工作人員可用管理 PIN 開啟現場清單、出席統計與識別證領取登記
